Give your AI agents a valet key, not your master key.

KeyValet is a local credential broker for AI agents on macOS. Claude Code, Codex, Cursor and other MCP agents use your API keys and OAuth accounts without ever seeing them: the secrets stay in a Secure Enclave-protected, root-only vault, you approve with Touch ID — per credential or per use — and per-use prompts show the real request.

A valet key starts the car but doesn’t open the trunk.

agent 需要钥匙时，发生了什么

四步完成，秘密始终留在只有 root 能读的凭证库里。

  1. agent 发出请求

    通过 MCP 说明要用哪个凭证、为了什么。

  2. 你来批准

    Touch ID 弹窗显示凭证和这次授权放开的能力。逐次模式下显示真实请求——方法、域名、路径，以及已知 API 的关键业务字段——按一次，只授权这一笔。

  3. KeyValet 代为调用

    root 进程注入 key，只发往你允许的域名，并抹掉响应里回显的秘密。

  4. agent 拿到结果

    返回响应，记录会话、目的和结果。会话结束，授权随之失效。

{%- else -%}

What happens when an agent needs a key

Four steps, and the secret never leaves the root-only vault.

  1. The agent asks

    Over MCP, naming the credential and saying why it needs it.

  2. You approve

    Touch ID shows the credential and what the grant allows. In per-use mode it shows the real request — method, host, path, plus the business fields that matter for known APIs — and one touch approves exactly that call.

  3. KeyValet makes the call

    A root helper injects the key, only toward hosts you allowed, and redacts anything that echoes it back.

  4. The agent gets the answer

    Response in; session, purpose and result logged. The grant ends with the session.

认证的事交给它，agent 不用操心

agent 拿到的是短期 token 或代理后的响应。refresh token、私钥和种子都留在凭证库里。

  • API key 与 token约 50 个现成模板（OpenAI、Anthropic、Gemini、GitHub、Stripe、Notion、Slack 等），以及通用的 bearer、header、query、basic 认证。
  • OAuth 2.0浏览器登录（PKCE）、设备码、客户端凭证，自动刷新。支持 Google、GitHub、Microsoft 和任意 OIDC 服务。
  • 给 SDK 用的本地网关把 SDK 的 base URL 指向 KeyValet（OPENAI_BASE_URL 风格），支持流式输出，程序拿不到真实 key。
  • Google service account 与 GitHub App在凭证库内签名换取 token，agent 只拿到一小时有效的 token。
  • AWSSTS 临时凭证、AssumeRole，并可用保存的 TOTP 种子完成 MFA。
  • TOTP 与签名 JWT当前的两步验证码；按模板签发 App Store Connect 这类 JWT。

It handles the auth, so agents don’t have to

Agents receive short-lived tokens or proxied responses. Refresh tokens, private keys and seeds stay in the vault.

  • API keys & tokensAbout 50 ready-made templates — OpenAI, Anthropic, Gemini, GitHub, Stripe, Notion, Slack — plus generic bearer, header, query and basic auth.
  • OAuth 2.0Browser sign-in with PKCE, device code, client credentials, automatic refresh. Google, GitHub, Microsoft, any OIDC provider.
  • Local gateway for SDKsPoint an SDK’s base URL at KeyValet (OPENAI_BASE_URL-style); streaming works and the program never holds the real key.
  • Google service accounts & GitHub AppsSigned JWT exchanges inside the vault; agents get one-hour tokens.
  • AWSSTS temporary credentials, AssumeRole, and MFA codes from a stored TOTP seed.
  • TOTP & signed JWTsCurrent two-factor codes; App Store Connect–style JWTs from a template.

能找到的密钥，帮你收进凭证库

钥匙不会自己走进凭证库，所以 KeyValet 帮你把它们找出来。

  • keyvalet scan在 .env*、~/.claude.json、.cursor/mcp.json、~/.codex/config.toml 和 shell 启动文件里找可能的密钥；勾选后按匹配模板导入为「仅代理」，并从原文件移除（留备份）。
  • 编辑器 hookClaude Code、Codex、Cursor、Grok、Devin 的原生 hook 适配器：粘贴或硬编码进文件、命令行的 key 会被识别并引导进 KeyValet。
  • 审计日志每次解锁、授权、读取、取 token、代理调用和配置修改都记录在只有 root 能读的日志里——秘密本身从不写入。
{%- else -%}

It finds the keys you already have

Keys don’t walk into a vault by themselves, so KeyValet helps collect them.

  • keyvalet scanFinds possible secrets in .env*, ~/.claude.json, .cursor/mcp.json, ~/.codex/config.toml and shell rc files; you check what to import, it stores them proxy-only from their matching template and removes them from the file (with a backup).
  • Editor hooksNative hook adapters for Claude Code, Codex, Cursor, Grok Build and Devin CLI: a key pasted or hard-coded into a file or command is flagged and redirected into KeyValet before it lands.
  • Audit logEvery unlock, grant, read, token fetch, proxied call and configuration change lands in a root-only log — the secrets themselves never do.

能保证什么，不能保证什么

凭证工具应该讲清楚自己的边界。完整的安全模型见 SECURITY.md，或本站的安全摘要。

能保证

  • 没有设备主人认证，任何凭证都用不了。
  • 协议凭证的长期秘密不出 root 进程；仅代理凭证永不返回明文。
  • 新增域名、放宽规则、覆盖或删除都要你确认，由 root 进程强制，而不是面向 agent 的服务端。
  • 每次使用都有记录，记录里从不出现秘密。

不能保证

  • 你授权过的 agent，可以在授权范围内滥用这次授权。
  • 目的是 agent 的自述，记录但不做核验；root 或 macOS 被攻破也防不住。
  • 用 credential_get 取出的值会进入 agent 的上下文。
{%- else -%}

What it guarantees, and what it doesn’t

A credential tool should be precise about its limits. The full model is in SECURITY.md, or read the security summary.

Guaranteed

  • No credential is used without device-owner authentication.
  • Long-term protocol secrets never leave the root helper; proxy-only credentials are never returned.
  • Adding hosts, loosening rules, overwriting or deleting needs your confirmation — enforced by root, not by the agent-facing server.
  • Every use is logged; secrets never are.

Not guaranteed

  • An agent you granted a credential can misuse that grant within its scope.
  • The purpose is the agent’s claim — recorded, never verified; compromised root or macOS is out of scope too.
  • Values you choose to reveal with credential_get are in the agent’s context.

安装

一条命令。它会下载由 Simvito Limited Developer ID 签名的发布包并校验 SHA256SUMS，要你输一次密码，并自动配置好已安装的 Claude Code、Codex、Cursor、Grok、Devin CLI。重跑即可升级。

curl -fsSL https://keyvalet.dev/install.sh | sh

需要 Apple Silicon、macOS 14+（Intel 可从源码构建）。卸载：curl -fsSL https://keyvalet.dev/install.sh | sh -s -- --uninstall

然后直接对 agent 说：

“用 KeyValet 的 openai 模板保存我的 OpenAI key。”
“用 KeyValet 列出我的 OpenAI 模型。”

key 由你在原生对话框里输入，使用时由你用 Touch ID 批准。agent 始终看不到它。

Install

One command. It downloads the release package signed with Simvito Limited’s Developer ID, verifies it against SHA256SUMS, asks for your password once, and sets up Claude Code, Codex, Cursor, Grok and Devin CLI if they’re installed. Run it again to upgrade.

curl -fsSL https://keyvalet.dev/install.sh | sh

Needs Apple Silicon with macOS 14+ (Intel builds from source). Uninstall with curl -fsSL https://keyvalet.dev/install.sh | sh -s -- --uninstall

Then just ask your agent:

“Store my OpenAI key in KeyValet with the openai template.”
“Use KeyValet to list my OpenAI models.”

You type the key into a native dialog, and approve its use with Touch ID. The agent never sees it.
