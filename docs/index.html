Give your AI agents a valet key, not your master key. 给 AI agent 一把代客钥匙，而不是你的万能钥匙。

KeyValet lets Claude Code, Cursor and other AI agents use your API keys and OAuth accounts without ever seeing them. You approve each credential with Touch ID, KeyValet makes the call, and every use is written down. KeyValet 让 Claude Code、Cursor 等 AI agent 使用你的 API key 和 OAuth 账号，却看不到它们。每个凭证由你用 Touch ID 批准，由 KeyValet 代为调用，每次使用都有记录。

Install on macOS在 macOS 上安装 Read the source查看源码

Open source (Apache-2.0). Runs entirely on your Mac. Works with any MCP client. 开源（Apache-2.0）。完全在你的 Mac 上运行。支持任何 MCP 客户端。

What happens when an agent needs a keyagent 需要钥匙时，发生了什么

Four steps, and the secret never leaves the root-only vault.四步完成，秘密始终留在只有 root 能读的凭证库里。

  1. The agent asksagent 发出请求

    Over MCP, naming the credential and saying why it needs it.通过 MCP 说明要用哪个凭证、为了什么。

  2. You approve你来批准

    Touch ID shows the credential and the purpose. One touch, one credential.Touch ID 弹窗写明凭证和目的。按一次，只授权这一个。

  3. KeyValet makes the callKeyValet 代为调用

    A root helper injects the key, only toward hosts you allowed, and redacts anything that echoes it back.root 进程注入 key，只发往你允许的域名，并抹掉响应里回显的秘密。

  4. The agent gets the answeragent 拿到结果

    Response in, purpose and result logged. The grant ends with the session.返回响应，记录目的和结果。会话结束，授权随之失效。

What it guarantees, and what it doesn’t能保证什么，不能保证什么

A credential tool should be precise about its limits. The full model is in SECURITY.md.凭证工具应该讲清楚自己的边界。完整的安全模型见 SECURITY.md。

Guaranteed能保证

  • No credential is used without device-owner authentication.没有设备主人认证，任何凭证都用不了。
  • Long-term protocol secrets never leave the root helper.协议凭证的长期秘密不出 root 进程。
  • Adding hosts, loosening rules, overwriting or deleting needs your confirmation — enforced by root, not by the agent-facing server.新增域名、放宽规则、覆盖或删除都要你确认，由 root 进程强制，而不是面向 agent 的服务端。
  • Every use is logged; secrets never are.每次使用都有记录，记录里从不出现秘密。

Not guaranteed不能保证

  • An agent you granted a credential can misuse that grant within the session.你授权过的 agent，可以在本会话内滥用这次授权。
  • The purpose is the agent’s claim. Read it before you touch.目的由 agent 自己填写，按指纹前请先读一读。
  • Values you choose to reveal with credential_get are in the agent’s context.用 credential_get 取出的值会进入 agent 的上下文。

Install安装

Needs macOS, Node.js 20+ from nvm or nodejs.org, and the Xcode Command Line Tools. The installer asks for your password once and adds a single sudoers rule that can only start the KeyValet helper.需要 macOS、来自 nvm 或 nodejs.org 的 Node.js 20+，以及 Xcode 命令行工具。安装时会要一次密码，并添加一条只能启动 KeyValet helper 的 sudoers 规则。


cd keyvalet
./scripts/install.sh

Then register it with your MCP client. For Claude Code:然后在 MCP 客户端里注册。以 Claude Code 为例：

claude mcp add keyvalet --scope user -- \
  /usr/local/lib/keyvalet/bin/node \
  /usr/local/lib/keyvalet/app/dist/server/index.js

Ask your agent to store a key with the openai template, then to list your models. You will see the Touch ID prompt once.让 agent 用 openai 模板保存一个 key，再列出你的模型。你只会看到一次 Touch ID 弹窗。
