repository's source code — that license covers the code, not the name or
logo.

## What's fine without asking

- Saying truthfully that your project, plugin, or integration works with
  KeyValet, is based on KeyValet, or is a fork of KeyValet — e.g. "Acme
  Sync for KeyValet" or "a KeyValet fork with X added."
- Using the name and logo in articles, tutorials, talks, and directory
  listings to refer to the project.
- Using an unmodified release of KeyValet, under its own name, as
  distributed.

## What needs permission

- Naming your own project, product, or company "KeyValet" or something
  confusingly similar.
- Using the KeyValet logo to imply your fork, service, or integration is
  the official project when it isn't.
- Registering a domain name or social media handle that could be mistaken
  for an official KeyValet account.

If you're not sure whether your use is fine, ask — open a discussion on the
repository or email **support@simvito.com**.

## Why this exists

The source is Apache-2.0 so anyone can read it, audit it, fork it, and run
their own build. The trademark policy exists separately so that when
someone sees "KeyValet," they can trust it refers to this project, built
the way this project is built — not a same-named fork with different
security properties.
